Quem está começando a programar deve instalar o Visual Studio Code. É grátis, é o editor dos tutoriais e não cobra em dólar para você aprender o que é um arquivo. O Cursor vale quando você já tem um projeto e consegue recusar uma sugestão errada. Antes disso, ele acelera o hábito de aceitar código que você não explica.

Os dois são primos. O Cursor é um editor com a cara do VS Code e um modelo por cima, focado no repositório. A diferença não é “qual tem mais IA”. É se você já lê o que aparece na tela.

## O que cada um cobra

O VS Code não tem mensalidade. Extensão, terminal e Git cabem no download. A conta Microsoft é opcional para sincronizar configuração. Para aula, faculdade e o primeiro script, isso é o produto inteiro.

O Cursor separa um modo gratuito limitado de uma assinatura. O preço é em dólar. No cartão brasileiro entram IOF e a cotação do dia, e o valor muda: não trate print antigo de “US$ 20” como tabela eterna. Olhe a página de preço na hora. Se a assinatura custa mais do que você gasta com o curso, ela está cedo.

O que o Cursor faz de útil está na matéria [Cursor não é IA que escreve código](/noticia/cursor-nao-e-ia-que-escreve-codigo): autocomplete que viu o repositório, não um chat que gera o projeto do zero. Isso ajuda quem já sabe o nome do arquivo. Para quem está no “o que é uma função”, a sugestão longa esconde a lição.

## Como não pular a parte que ensina

Use o VS Code até você conseguir, sem colar:

- criar um arquivo, rodar, ler o erro e corrigir uma linha;
- abrir o Git e explicar o que o diff mudou;
- instalar uma extensão e desinstalar se ela atrasar o editor.

Aí o Cursor, ou o modo gratuito, serve como segunda opinião. A regra é a mesma do [contexto maior que o prompt](/noticia/contexto-maior-que-prompt): diga o que não fazer e leia o trecho. Se você não sabe dizer se a sugestão está certa, você ainda está na fase do VS Code.

Não comece um curso “de Cursor”. Comece um curso da linguagem. O editor não é a matéria. Faculdade e emprego vão abrir o VS Code, o editor da JetBrains ou o que já estiver no repositório. Atalho exótico de um fork pago não transfere.

Privacidade: os dois podem enviar trecho de código ao usar recurso de nuvem. Projeto de cliente e senha não entram no chat. Isso vale em dobro para quem está começando e ainda não separa arquivo de exemplo de arquivo real.

## Veredito

VS Code agora. Cursor quando o repositório existir e a assinatura em dólar couber sem substituir o tempo de ler o erro. Aceitar arquivo gerado que você não explica não é começar mais rápido. É terceirizar a única prática que ensina.
