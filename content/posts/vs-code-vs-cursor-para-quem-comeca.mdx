Para quem está começando a programar no Brasil, a melhor compra pode ser não comprar uma assinatura. O Visual Studio Code permite editar, executar e depurar projetos sem mensalidade. O Cursor oferece recursos de assistência no editor e uma versão gratuita, mas pagar por mais geração de código não resolve a dificuldade de entender o primeiro erro. Nossa recomendação é começar pelo ambiente indicado no curso e só mudar quando houver um problema concreto que a troca resolva.

Isso não transforma o Cursor em ferramenta proibida para iniciantes. Uma explicação de erro pode ajudar; uma alteração de vinte arquivos que você não consegue revisar pode atrapalhar. A escolha deve considerar dinheiro, controle sobre o projeto e privacidade, não a promessa de que determinado editor elimina a necessidade de aprender.

## O que você recebe sem pagar

A [Microsoft confirma que o VS Code é gratuito](https://code.visualstudio.com/docs/supporting/FAQ) para uso pessoal e comercial. Também não exige conta para instalar ou usar o núcleo do editor. Isso permite estudar e desenvolver projetos sem contratar o Copilot. Recursos de assistência em nuvem, extensões e serviços conectados têm condições próprias; a gratuidade do editor não torna todo complemento gratuito.

O VS Code reúne edição, depuração, tarefas e controle de versão. O programa roda em Windows, macOS e Linux, respeitadas as versões suportadas. Não é necessário escolher o editor mais complexo: para aprender uma linguagem, o importante é conseguir abrir o arquivo, executar o programa, ler a mensagem de erro e localizar a linha responsável.

O [Cursor Free](https://cursor.com/pt-BR/help/account-and-billing/pricing) oferece Agent, Chat e autocompletar com uso limitado. É uma maneira de experimentar a proposta sem assumir mensalidade. Não tratamos essa franquia como quantidade garantida de projetos: limites e consumo dependem do plano e dos recursos usados. Confira a tabela vigente antes de decidir com base em um vídeo antigo.

## Quanto custa para quem paga em reais

Na consulta para esta revisão, a [tabela oficial do Cursor](https://cursor.com/pricing) apresenta Free, Plus a US$ 8 mensais e Premium a US$ 30 mensais, além dos níveis superiores. A documentação identifica o antigo Pro de US$ 20 como plano legado. Portanto, não faz sentido comparar o VS Code gratuito com uma tabela histórica como se ela fosse a oferta atual para todo novo cliente.

O Plus tem restrições, incluindo ausência de modelos de terceiros; no Premium, o uso desses modelos é cobrado separadamente. Os preços publicados não incluem impostos. Comprar o nível mais barato sem conferir os modelos disponíveis pode deixar de atender justamente o recurso que motivou a assinatura.

Para dar escala ao orçamento brasileiro, o [Banco Central registrou dólar de venda de R$ 5,4212 na PTAX de 30 de outubro de 2026](https://ptax.bcb.gov.br/ptax_internet/consultarTodasAsMoedas.do?method=consultaTodasMoedas). Nessa referência, US$ 8 equivalem a aproximadamente **R$ 43,37** e US$ 30 a **R$ 162,64**. São conversões informativas, não preços brasileiros nem valores finais de fatura: faltam o câmbio efetivo do pagamento, impostos e eventuais cobranças adicionais.

O VS Code, por sua vez, custa **R$ 0** como editor. Ambos têm páginas públicas de download; o [Cursor informa versões para os três sistemas de desktop](https://cursor.com/download). Não verificamos um preço fixo em reais para sua assinatura. Antes de pagar, confira moeda, renovação e total exibido na contratação. Para estudar sem risco cambial de mensalidade, as opções gratuitas são o ponto de partida mais simples.

## Um projeto pequeno decide mais que uma lista de recursos

Nossa proposta é usar o mesmo exercício nos dois ambientes: um programa que leia uma lista de despesas e some os valores. Primeiro, faça a versão mínima funcionar. Depois acrescente uma regra, como recusar valor negativo. Guarde a alteração no Git e leia o diff, a comparação entre as versões.

Antes de aceitar uma sugestão, responda: qual arquivo mudou, qual comportamento foi acrescentado e como conferir se ele funciona? Rode também entradas vazias ou inválidas. Isso não é um teste de desempenho dos editores, mas um critério de estudo: se você só reconhece o resultado na tela e não entende o caminho, aumentar a geração de código não corrige a lacuna.

Use a assistência para pedir uma explicação curta ou comparar duas soluções. Evite começar solicitando um aplicativo completo. Para organizar perguntas com objetivo e limites, o nosso [guia sobre contexto e instruções](https://www.thezero.com.br/noticia/contexto-maior-que-prompt) ajuda a separar o pedido do material necessário para respondê-lo.

## Privacidade não se resume a desligar uma opção

A documentação do Cursor explica que recursos de assistência enviam prompts e contexto de código aos provedores. O [Privacy Mode](https://cursor.com/help/security-and-privacy/privacy) impede o uso do código para treinamento, segundo a empresa; isso não significa execução exclusivamente local. Chaves próprias e determinados modelos têm exceções às condições de retenção.

No VS Code, é possível desativar recursos integrados de assistência e configurar `telemetry.telemetryLevel` como `off`. A Microsoft ressalva que extensões podem coletar dados por conta própria. Para um estudante que começa a prestar serviços, a consequência prática é importante: projeto de cliente, credencial e cadastro real não devem entrar em ferramentas de nuvem sem conferir autorização e condições. Pratique com dados fictícios.

## O que isso significa

Nossa leitura é que o orçamento deve seguir uma habilidade demonstrada, não antecedê-la. Se a opção gratuita permite concluir o exercício e acompanhar o curso, a mensalidade ainda não é necessária. Quando você consegue revisar mudanças e identifica uma tarefa repetitiva que a assistência resolve, experimentar o Cursor pode fazer sentido. Primeiro use a versão gratuita e observe seus limites.

A conta brasileira inclui o custo recorrente em reais e a possibilidade de cobrança adicional, mas também o tempo gasto conferindo sugestões. Não afirmamos que um editor ensina melhor ou entrega ganho medido de produtividade: não realizamos esse teste. Recomendamos o VS Code como início de baixo compromisso financeiro; o Cursor entra como escolha consciente, não como condição para aprender.
